FREE PUBLISHING WITH GITHUB PAGES:
1. Sign in or create a free account at https://github.com
2. Create a public repository named ms-fabrication-website.
3. Upload index.html and the complete images folder (keep the folder structure).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish and open the website address shown there.

The free address uses github.io; a custom .com/.in domain is optional and costs extra.
Before publishing, confirm the contact details and that the gallery images are suitable
to represent your work. If any image is a reference/example rather than your own project,
label it accordingly or replace it with your own completed-work photo.
